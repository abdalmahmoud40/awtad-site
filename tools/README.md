# أداة إنشاء موقع أوتاد النخبة

هذا المجلد لا يظهر في الموقع. يحتوي على `build_awtad.py` الذي يُنشئ كل صفحات `public` (العربية والإنجليزية، خريطة الموقع، التحويلات).

- المنتجات: قائمة `PROD` داخل الملف (التصنيف، الصورة، الاسم والوصف بالعربي والإنجليزي).
- القطاعات: قائمة `SECT`.
- الأرقام: `FIG`، والأسئلة الشائعة: `FAQ`، وبيانات التواصل في أعلى الملف.
- التنسيق في `public/assets/style.css` (لا تولّده الأداة).

التشغيل: `python3 tools/build_awtad.py` ثم رفع مجلد `public` المحدّث.
عند طلب تعديل من Claude: أرسل له هذا الملف أو رابط المستودع.
